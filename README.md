# 《星隕編年史：霧海遺城》(Chronicles of Starfall) — Monster Hunter 3D Edition v4.0

## 專案簡介
《星隕編年史：霧海遺城》是一款專為 macOS 打造的 **《魔物獵人》風格 3D 越肩狩獵 × 2D HD 像素雙模式切換 × 15 座 40x28 巨型地城 × 斬味系統 × 魔物部位破壞斷尾 × 戰術破盾 RPG**。  
本版本在原有 15 座巨型地城基礎上全面升級為 **3D 魔物獵人狩獵紀元**：
- **3D 透視渲染引擎 (`js/mh3d.js`)**：零外部依賴、純原生 HTML5 Canvas 數學透視投影，支援 `[V]` 鍵即時切換 **【2D 經典像素視角 (預設)】**、**【3D 越肩狩獵視角】** 與 **【3D 廣角戰術視角】**，支援 `[J]/[L]` 旋轉 3D 鏡頭，並以翠綠色**導蟲粒子流 (`Scoutflies`)** 在 3D 空間中引領獵人探索。
- **《魔物獵人》核心狩獵系統**：
  - **武器斬味計量表 (Sharpness Gauge)**：紅 ➔ 橙 ➔ 黃 ➔ 綠 ➔ 藍 ➔ 白 ➔ **紫斬 (1.38x 傷害加成)**，出招消耗斬味，按 **`[R]` 鍵（砥石研磨）** 可立即磨刀恢復 100 滿額紫斬並獲得 2 回合【剛刃研磨】。
  - **魔物三部位鎖定破壞與斷尾 (Part Break & Tail Sever)**：戰鬥中可隨時鎖定魔物的 **【頭部 Head】**（破頭觸發氣絕 KO 破盾 2 點並永久削弱魔物攻擊）、**【軀幹 Body】**（弱點肉質 +15% 傷害，擊碎胸甲附加易傷）、**【尾巴 Tail】**（累積斬擊觸發【斷尾成功 TAIL SEVERED!】，立即剝取稀有素材與賞金，並在 3D 畫布呈現斷尾殘骸）。
  - **魔物紅蓮憤怒狀態 (`Enraged`)**：魔物血量低於 65% 時發出震耳咆哮激發全身赤紅鬥氣。
  - **太刀氣刃計量槽與 `[X]` 見切迴避斬**：減免 65% 傷害並在敵方出手時以【氣刃大迴旋】反擊破盾，將太刀氣刃升階至白刃 (+8% 攻)、黃刃 (+16% 攻) 或紅刃極意 (+25% 攻)。
  - **獵人公會星辰貓飯料理亭 (`[G]` 鍵)**：營火或頂部按鈕可享用攻大、防大、幸運剝取三大貓飯套餐，回滿體力、磨亮紫斬並獲得持續 4 場狩獵的料理增益。
- **全專案 100% 嚴格零 Emoji**：全手繪像素圖示與精緻文字標籤，兼顧現代 3D 運鏡與經典復古美感。

## 技術棧
- **前端核心**：原生 HTML5 Canvas 2D / 3D 透視投影矩陣 + Vanilla JavaScript (ES6+) + CSS3（零外部依賴，100% 支援 `file://` 離線直接執行）
- **3D 狩獵引擎**：自研 `MH3DRenderer` 3D 透視投影、深度排序 (Painter's Algorithm)、射線地面反向解算 (`screenToWorldTile`)、多部位魔物模型與導蟲粒子
- **美術渲染**：自研 16x16 原生像素矩陣渲染引擎 (`PixelArtEngine`)，全專案 100% 零 Emoji
- **音效系統**：WebAudio API 程序化作曲（五章各自調式與速度的探索曲，加上戰鬥與首領曲，含和弦、旋律、低音、琶音、鼓組與殘響）與 12 種動態音效 (`SoundSystem`)
- **資料儲存**：`localStorage` 多槽位存檔（自動存檔 + 3 組手動存檔槽）與 `.json` 存檔匯出/匯入
- **自動化測試**：Node.js 原生 `assert` 測試套件 (`StarfallChronicles/tests/test_game.js`)，包含 13 大自動化測試與 7 大核心檔案 100% 零 Emoji 檢查

## 安裝與環境設定
本專案為 **100% 免安裝、零外部依賴** 架構，無須安裝任何第三方套件即可直接遊玩。  
若需執行自動化測試套件，僅需 macOS 內建或已安裝之 `node`（Node.js v16+）。

## 啟動與使用方式

### 1. 啟動遊戲（三種方式任選）
- **方式一（Mac 原生應用程式）**：在 Finder 雙擊根目錄的 [`星隕編年史.app`](./星隕編年史.app)。
- **方式二（啟動腳本）**：在 Finder 雙擊 [`啟動星隕編年史.command`](./啟動星隕編年史.command)。
- **方式三（瀏覽器直接開啟）**：直接以 Safari / Chrome / Edge 開啟 [`StarfallChronicles/index.html`](./StarfallChronicles/index.html)。

### 2. 核心操作快捷鍵
- `WASD` / `方向鍵`：在地圖或 3D 空間中移動主角獵人
- `點擊地圖 / 小地圖`：滑鼠左鍵點擊地面，自動以 3D 射線投射解算並尋路前往
- `[Tab]`：開關角色面板抽屜（能力值、夥伴、裝備、藥水、方向鍵）
- `[V]`：切換視角（2D 經典像素 ➔ 3D 越肩狩獵 ➔ 3D 廣角戰術）
- `[J]` / `[L]`：向左 / 向右旋轉 3D 鏡頭方位
- `[R]`：砥石磨刀（將武器研磨至 100 紫斬，並獲得剛刃研磨狀態）
- `[G]`：打開獵人公會星辰貓飯料理亭視窗
- `[Q]`：施放星輝脈衝（破除秘牆、拆解陷阱、震懾魔物觸發先制奇襲）
- `[E]`：切換武器五屬性附魔（物理 / 星輝 / 烈焰 / 寒霜 / 虛空）
- `[M]`：切換 40x28 全景戰略地圖

**即時戰鬥（直接在地圖上進行，沒有回合與等待）**
- 底部技能列平時就常駐：探索中隨時按 `[Space]` / `[1]`~`[9]` 就能攻擊——附近（近戰 4 格內會自動衝刺、魔法 5 格內）有魔物會直接出招並開戰，不必先碰到；附近沒有魔物則揮劍氣示意，治療技能可直接補血
- 碰到魔物即開戰：魔物會追著你跑，出招前地面會出現**紅色預警圈**，圈滿即命中——走位離開或翻滾閃避
- `WASD` / `方向鍵`（按住持續移動）：走位
- `[1]`~`[9]` / 點擊技能列：施放技能，各有冷卻；近戰技能距離不足時會自動衝刺貼近，魔法技能可遠距離施放
- `[Space]`：基礎斬擊（星芒斬）
- `[X]`：見切翻滾（朝移動方向位移 2 格並短暫無敵；無敵時被擊中會發動氣刃大迴旋並升階氣刃）
- `[3]` 星紋障壁：剛展開 0.35 秒內擋下強擊 = 完美防反
- `[C]`：星靈協同大招（能量滿 100% 後）
- `[H]`：喝回復藥（依序用治療藥水、高階靈藥、鳳凰涅槃膏）　`[N]`：喝魔力飲
- `[Z]` / 點擊魔物狀態列：切換鎖定部位（頭部 / 軀幹 / 尾巴）
- `[R]`：砥石磨刀　`[E]`：切換武器附魔　`[T]`：自動戰鬥　`[F]`：撤退（持續 1.6 秒不被擊中，首領戰不可撤退）
- 魔物攻擊有四種預警：近身圓形、直線衝鋒、前方扇形與遠程落點彈幕；命中有傷害數字與打擊停頓；戰敗會損失 15% 金幣
- 連擊計數（3 秒內持續命中累加，純顯示）；勝利後顯示戰鬥結算卡（用時、最高連擊、受傷量、獎勵與 S/A/B/C 評價）；第一場戰鬥有情境引導提示
- 耗星力的技能倍率高於免費的星芒斬（爆發輸出），星芒斬負責回魔與穩定輸出
- 打斷：耗星力的重擊在魔物出招前搖中命中，會取消該次攻擊並使牠後退硬直（首領僅被破部位或奧義打斷）；出招後有短暫硬直不能走位；魔物生命低於 25% 會疲憊、動作變慢
- 狩獵循環：打倒魔物會剝取素材（破壞軀幹得皮革、頭部得利牙、斷尾得稀有核心，另有額外剝取）；首領素材可在鐵砧鍛造專屬獵刃與重鎧，精英素材鍛造護符，鍛造視窗「狩獵裝備」區在討伐後才會出現配方
- 護盾打破後魔物會暈眩，恢復後護盾「硬化」數秒（一般 6 秒/精英 9 秒/首領 12 秒）無法再打破，避免連暈；魔物傷害與血量已針對即時戰鬥放大，不翻滾硬吃會很痛
- 無盡星淵（右側傳送圖示）：可重複挑戰的爬塔，每層固定詞綴（豐饒/猛攻/堅殼/狂暴）、層主通關必得稀有核心與金幣，每 5 層噬星者守關並有里程碑獎勵；可從通關過的里程碑下一層開始，也可隨時從視窗離開回到原位置
- 獵人公會（右側「委託板」按鈕）：每章 8~9 件委託（獵殺、剝取素材、菁英討伐、等級、鍛造、星淵層數），共 40 件，完成可領金幣/經驗/道具/技能點；**每章需完成 6 件（含菁英討伐）才能挑戰該章首領**。一般魔物會在營火休息或重進區域後重生，可放心刷怪；等級遠高於該章建議等級時經驗遞減
- 公會訓練場（委託板的第二個分頁）：用金幣永久強化體魄/武藝/守備/星力，各 10 階、越往上越貴；星界行商第 2~3 章起會進更高階補給
- 故事支線與劇情場景：每章 2 條三段式故事（地圖上標示「（故事）」的 NPC，接取 → 完成條件 → 回報後下一段，跨 1~3 子區域，只在對應章節出現），完成後解鎖專屬手札（共 10 篇，手札越多越容易解鎖共生/隱藏結局）；每章還有 3 段劇情場景對話，首次閱讀有小獎勵；任務面板會列出本章故事進度
- 右側工具列「音量」可分別調整背景音樂與音效
- 戰鬥時固定使用 2D 畫面；護盾打空會讓魔物暈眩約 3 秒並承受 1.4 倍傷害

### 3. 執行自動化測試
```bash
node StarfallChronicles/tests/test_game.js
# UI 互動測試（假 DOM 驅動視窗與按鈕）
node StarfallChronicles/tests/test_ui.js
# 通關機器人：從 1-1 自動玩到終章結局選擇，確認主線可通關
node StarfallChronicles/tests/playthrough.js
```
